# 孕妇闻风油精对胎儿有影响吗？

孕妇闻风油精对胎儿有影响吗？更新时间:2022-08-23

夏天天气炎热，蚊虫多，有些人就会涂抹风油精。如果身边的人涂抹了风油精，作为孕妈妈的我们需不需要回避呢？孕妇闻风油精对胎儿有影响吗？

风油精有清凉、止痛、驱风、止痒的作用。它的主要成分和清凉油一样，含有樟脑、薄荷、麝香和桉叶油。樟脑具有一定毒性。一般正常人涂抹了风油精，体内的葡萄糖磷酸脱氢酶会很快地与樟脑结合,使之变成无毒物质,然后随小便一起排出体外,所以不会发生不良反应。然而由于孕期生理上的变化,孕妈妈体内的葡萄糖磷酸脱氢酶的含量会降低，尤其是头3个月。这3个月内，孕妈妈若过多地使用风油精,樟脑就会通过皮肤吸收进入体内,然后再通过胎盘屏障进入羊膜腔内作用于胎儿,影响胎儿生长发育,严重的可导致胎儿畸形,或。怀孕头3个月,正是胎儿处于器官分化阶段,其伤害更明显,危害更大。

风油精里含有麝香，麝香这种东西，连宫斗剧都会告诉我们，它会导致流产。所以呢，孕妇是不宜涂清凉油,风油精这些东西的。各位孕妈妈，请不要随便用！否则会影响肚子里的小宝宝。如果只是闻到气味还是没有很大关系的，不过还是注意点比较好。孕妇是必须要慎用风油精的，所以最好不要常在这种环境下工作。而我们自己孕期最好是不要使用清凉油和风油精为好，都会有所影响的。偶尔闻这种味道，不会有太大的问题，但是长期在这种环境下就不好了。如果长期呆在这种环境，我们就要采取措施来避免这种现象了。
